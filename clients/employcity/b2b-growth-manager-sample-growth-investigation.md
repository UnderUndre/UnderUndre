# Демонстрационный кейс: Расследование аномалии NGR у B2B-оператора

*Приложение к отклику на роль B2B Growth Manager*  
*Цель: Демонстрация методологии поиска причин, проверки гипотез и разделения мер на Run и Change.*

---

## 1. Входной сигнал (Trigger Incident)

В понедельник в BI-дашборде зафиксирован алерт:

- **Симптом:** Чистая выручка (NGR) крупного B2B-оператора за прошедшую неделю просела на **-17.4% WoW**.
- **Реакция Account Management:** Запрос в разработку: *«У оператора сломался платежный модуль или отвалились игроки, срочно чините»*.

---

## 2. Экспресс-проверка ложных тревог (False Positives Filter)

Прежде чем формулировать гипотезы о поведении игроков или багах платформы, исключаем системные шумы:

1. **Календарный фактор / лаг DWH:** Сверка таймстампов репликации базы. Логи засинхронизированы без задержек.
2. **RTP Variance (Дисперсия выигрышей):** Общий оборот ставок (Turnover) стабилен (+1.2% WoW), а фактический RTP составил 95.8% (в пределах нормы). Значит, крупного выигрыша хайроллера не было, математика слотов не сломалась.

**Вывод:** Проблема лежит не в обороте ставок, а внутри конверсионной цепочки либо в стоимости удержания (NGR = GGR - Бонусы - Комиссии).

### Локализация проблемы

Действующая база игроков активна. Просадка NGR вызвана двумя синхронными факторами:

1. Резкий обвал конверсии в первый депозит (FTD) у новых регистраций.
2. Вымывание маржи из-за аномального роста бонусных расходов.

## 4. Реестр конкурирующих гипотез (Поиск причинности)

- **Гипотеза 1 (Продуктовый дефект кассы):**  
  *Проверка:* Провели срез Success Rate по платежным методам. У ключевых шлюзов успешность стабильна (79–82%). Ошибок 3D-Secure нет.  
  *Статус:* **ОПРОВЕРГНУТО (L1 логи платежей подтверждают исправность платформы).**

- **Гипотеза 2 (Сдвиг качества внешнего трафика):**  
  *Проверка:* Дрилл-даун трафика по источникам показал: оператор подключил новую партнерскую сеть (Source ID: 412), давшую +30,000 кликов. Конверсия в FTD из этого источника составила 0.9% против 8.4% по старым каналам.  
  *Статус:* **ПОДТВЕРЖДЕНО.**

- **Гипотеза 3 (Бонус-абьюз новой промо-акции):**  
  *Проверка:* Анализ когорты показал, что игроки из Source ID 412 массово активировали новый бездепозитный бонус, сгенерировав нагрузку на Bonus Cost без внесения реальных депозитов.  
  *Статус:* **ПОДТВЕРЖДЕНО.**

## 5. План действий: Разделение RUN и CHANGE

### RUN (Оперативные действия для Account Management — запустить сегодня)

1. **Инструкция для звонка с оператором:**
   - Показать оператору срез по источнику Source ID 412: трафик неконвертящий, вымывает бюджет. Рекомендовать отключить или пересмотреть условия CPA-сделки с данным аффилейтом.
   - Скорректировать настройки текущего бонуса в админке: повысить вейджер или ограничить выдачу бонуса только после прохождения валидации номера телефона.
2. **Ожидаемый эффект:** Немедленная остановка слива Bonus Cost, возвращение соотношения Bonus/GGR к целевым 18% за 48 часов.

### CHANGE (Задачи для Product Discovery платформы — бэклог разработки)

1. **Фича в Anti-Fraud Engine:** Доработать правила автоматического ограничения бонусных кампаний для источников с конверсией в депозит ниже пороговой (Trigger: if FTD CR < 2% upon 500 regs → Auto-Hold bonus issuance).
2. **UX кассы:** Выводить альтернативные локальные методы депозита с пуш-подсказкой, если пользователь закрыл окно оплаты, не совершив действие.
